# Car Parts Management System

## Περιγραφή

Η παρούσα εργασία αφορά την ανάπτυξη μιας web εφαρμογής για τη διαχείριση ανταλλακτικών αυτοκινήτων. Το σενάριο επιλέχθηκε επειδή η σωστή οργάνωση και παρακολούθηση των ανταλλακτικών αποτελεί βασική ανάγκη για συνεργεία αυτοκινήτων, καταστήματα ανταλλακτικών και επιχειρήσεις που διαχειρίζονται αποθέματα.

Στόχος της εφαρμογής είναι η απλοποίηση της καταχώρισης, αναζήτησης και διαχείρισης ανταλλακτικών μέσω ενός εύχρηστου περιβάλλοντος. Ο χρήστης μπορεί να προσθέτει νέα ανταλλακτικά, να προβάλλει τα διαθέσιμα προϊόντα, να αναζητά συγκεκριμένες εγγραφές και να διαγράφει δεδομένα που δεν είναι πλέον απαραίτητα.

Η εφαρμογή συμβάλλει στη μείωση των λαθών που μπορεί να προκύψουν από χειροκίνητη διαχείριση αρχείων, βελτιώνει την οργάνωση των πληροφοριών και επιτρέπει την ταχύτερη πρόσβαση στα δεδομένα της αποθήκης.

Παράλληλα, η εργασία συνδυάζει τεχνολογίες ανάπτυξης web εφαρμογών με βασικές έννοιες δικτύων υπολογιστών. Για τον σκοπό αυτό υλοποιήθηκε δικτυακή τοπολογία με routers, switches και υπολογιστές, χρησιμοποιώντας δυναμική δρομολόγηση RIP v2, ώστε να εξασφαλίζεται η επικοινωνία μεταξύ όλων των συσκευών του δικτύου.

**spare_parts**
- id (Primary Key)
- name
- category
- car_brand
- quantity
- price
- supplier


## Δικτυακή Αρχιτεκτονική

Το δίκτυο αποτελείται από:
- 2 υπολογιστές
- 5 routers
- 2 switches

Οι συσκευές συνδέθηκαν με κατάλληλη καλωδίωση και ρυθμίστηκαν με IP διευθύνσεις.

Για τη δρομολόγηση χρησιμοποιήθηκε το πρωτόκολλο RIP v2 με τις εντολές:
- version 2
- no auto-summary

Όλα τα interfaces ενεργοποιήθηκαν με την εντολή:
- no shutdown


## Έλεγχος Συνδεσιμότητας

Η επικοινωνία μεταξύ των συσκευών ελέγχθηκε με την εντολή:
ping 192.168.2.2

Το αποτέλεσμα ήταν επιτυχές με 0% packet loss, επιβεβαιώνοντας τη σωστή λειτουργία της δρομολόγησης.

## Συμπέρασμα
Η εργασία ολοκληρώθηκε με επιτυχία και κάλυψε τόσο το κομμάτι της ανάπτυξης web εφαρμογών όσο και το κομμάτι των δικτύων υπολογιστών. Συνδυάστηκαν διαφορετικές τεχνολογίες, όπως PHP, MySQL, HTML, CSS και Cisco Packet Tracer, για τη δημιουργία ενός ολοκληρωμένου συστήματος.

Το τελικό αποτέλεσμα είναι μια λειτουργική εφαρμογή διαχείρισης ανταλλακτικών αυτοκινήτων, η οποία επιτρέπει την εύκολη οργάνωση και διαχείριση δεδομένων, ενώ παράλληλα υποστηρίζεται από μια πλήρως λειτουργική δικτυακή υποδομή που εξασφαλίζει την επικοινωνία μεταξύ των συσκευών του δικτύου.
