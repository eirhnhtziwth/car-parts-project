# Car Parts Management System

## Περιγραφή
Η παρούσα εργασία αφορά την ανάπτυξη μιας web εφαρμογής για τη διαχείριση ανταλλακτικών αυτοκινήτων.  
Ο χρήστης μπορεί να προσθέτει, να βλέπει, να διαγράφει και να αναζητά ανταλλακτικά μέσα από ένα απλό και φιλικό περιβάλλον.


## Τεχνολογίες
- PHP
- MySQL
- HTML/CSS
- XAMPP


## Λειτουργίες Εφαρμογής

### Προσθήκη Ανταλλακτικού
Ο χρήστης εισάγει:
- Όνομα
- Κατηγορία
- Μάρκα
- Ποσότητα
- Τιμή
- Προμηθευτή

### Προβολή Ανταλλακτικών
Εμφανίζονται όλα τα ανταλλακτικά σε μορφή πίνακα.

### Διαγραφή
Δίνεται δυνατότητα διαγραφής εγγραφών με επιβεβαίωση.

### Αναζήτηση
Ο χρήστης μπορεί να αναζητήσει ανταλλακτικά με βάση:
- Όνομα
- Κατηγορία
- Μάρκα


## Βάση Δεδομένων

Η βάση δεδομένων περιλαμβάνει τον πίνακα:

**spare_parts**
- id (Primary Key)
- name
- category
- car_brand
- quantity
- price
- supplier


## Δικτυακή Αρχιτεκτονική

Το δίκτυο αποτελείται από:
- 2 υπολογιστές
- 5 routers
- 2 switches

Οι συσκευές συνδέθηκαν με κατάλληλη καλωδίωση και ρυθμίστηκαν με IP διευθύνσεις.

Για τη δρομολόγηση χρησιμοποιήθηκε το πρωτόκολλο RIP v2 με τις εντολές:
- version 2
- no auto-summary

Όλα τα interfaces ενεργοποιήθηκαν με την εντολή:
- no shutdown


## Έλεγχος Συνδεσιμότητας

Η επικοινωνία μεταξύ των συσκευών ελέγχθηκε με την εντολή:
ping 192.168.2.2

Το αποτέλεσμα ήταν επιτυχές με 0% packet loss, επιβεβαιώνοντας τη σωστή λειτουργία της δρομολόγησης.

## Συμπέρασμα
Η εφαρμογή καλύπτει βασικές λειτουργίες CRUD και αποτελεί ένα απλό σύστημα διαχείρισης αποθήκης ανταλλακτικών αυτοκινήτων.
Παράλληλα, η υλοποίηση της δικτυακής τοπολογίας συνέβαλε στην κατανόηση της επικοινωνίας μεταξύ συστημάτων και της δυναμικής δρομολόγησης.
